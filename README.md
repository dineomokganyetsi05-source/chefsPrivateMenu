# chefsPrivateMenu
Chefs Private Menu is an app that allows chefs to edit , add, view and shows ratings of dishes made by the chef 
The chef has the first option to add and delete
the dishes are categorized in to 3 sections 
starter
Main
Dessert 
The app also accommodates various currencies including Rands , Dollars and Pounds 
The chef can also manage the menus once added
